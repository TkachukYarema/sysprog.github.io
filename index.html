GIT

Git — розподілена система керування версіями файлів та спільної роботи. Git є однією з найефективніших, надійних і високопродуктивних систем керування версіями, що надає гнучкі засоби нелінійної розробки, що базуються на відгалуженні та злитті гілок. Для забезпечення цілісності історії та стійкості до змін заднім числом використовуються криптографічні методи, також можлива прив'язка цифрових підписів розробників до тегів і комітів.

Головні переваги Git можна перерахувати так:

  • розподілена архітектура з повною локальною копією репозиторію;
  • висока продуктивність при операціях з гілками та історією;
  • цілісність даних завдяки SHA-1 хешуванню;
  • потужні можливості розгалуження та злиття;
  • налаштовуваний набір низькоурівневих інструментів для робочих процесів;
  • відкритий вихідний код під ліцензією GNU GPL версії 2.

10 основних команд Git

  1. git init — ініціалізація нового Git-репозиторію
  2. git clone <url> — клонування віддаленого репозиторію
  3. git status — перевірка поточного стану репозиторію
  4. git add . — додавання змін до області підготовки (staging area)
  5. git commit -m "Повідомлення" — створення комміту зі змінами
  6. git log — перегляд історії коммітів
  7. git branch — перегляд та робота з гілками
  8. git checkout <branch> — перехід на іншу гілку
  9. git merge <branch> — об'єднання змін з іншої гілки
  10. git push origin master — відправлення локальних коммітів до віддаленого репозиторію
